# AI Design-to-Build Agent

An AI-powered solution that transforms 2D architectural floor plans into 3D visualizations with measurements and preliminary material quantity estimates.

## Core Workflow

2D Floor Plan → AI Analysis → 3D Visualization → Measurements → Material Estimation

## Project Goal

The goal is to simplify the process of moving from an architectural floor plan to a visualized and buildable interior concept, while automatically estimating key measurements and material quantities.
